# 介绍

EmbedScope 是用 Rust 构建的嵌入式诊断与控制工具。它将设备的日志、内存指标、UI 对象树和显示画面放到同一个调试流程中，通过命令行、桌面 Inspector 或主机 SDK 读取，也能通过平台输入接口复现点击。

设备运行轻量的 `no_std` Agent，主机通过 USB CDC、UART 等串口或 TCP 字节流连接。Agent 复用固件已有的任务调度、LVGL 实例和显示驱动，按平台实际提供的能力工作。

## 可以用它做什么

- **排查运行问题**：筛选结构化日志，观察空闲内存、连续空闲块、帧耗时和队列深度。
- **检查界面**：将控件层级、位置和尺寸与显示像素对应起来。
- **复现交互**：发送逻辑像素坐标上的点击，比较操作前后的页面、日志和截图。
- **保存现场**：导出包含固件身份、日志、指标、树、截图和崩溃摘要的诊断包。

每台设备通过握手声明能力。没有屏幕的设备可以只提供日志和指标；UI 框架也可以通过自定义元数据接入。各项功能的入口见[功能导航](./features.md)。

## 主机工具与设备 Agent

| 组件 | 作用 |
| --- | --- |
| `escope` | 命令行采集、JSON 输出、诊断导出和软件参考设备 |
| Inspector | 在原生桌面窗口检查对象、画面、指标与日志 |
| `escope-host` | 在 Rust 主机程序中管理连接、请求和事件 |
| `escope-agent` | 在设备上处理会话、日志与平台能力分发 |
| `escope-lvgl` | 连接 UI 对象元数据与现有 LVGL 实例 |
| `escope-c-api` | 为 C/C++ 固件提供 Agent 的 C ABI |

CLI 与 Inspector 使用同一套主机 SDK。设备只需接入一个 Agent，即可供这些工具使用。

## 从哪里开始

首次使用可按[快速开始](./quick-start.md)运行软件参考设备，完成一次身份读取、点击和截图。参考设备提供合成画面与指标，便于先熟悉工具。

已有 Agent 的设备从[连接设备](../basic/connection.md)开始。开发固件时，选择 [Rust 接入](../../integration/rust.md)、[C/C++ 接入](../../integration/c.md)或[团子 OS](../../integration/dango.md)。使用 LVGL 和 rs_lvgl 的工程可继续阅读 [LVGL 接入](../../integration/lvgl.md)。

当前版本从源码构建。设备刷写、OTA、文件管理和 ELF 符号解析由目标工程的其他工具承担。
